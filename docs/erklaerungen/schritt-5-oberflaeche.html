Oberfläche: drei Spalten, Beleg-Ansicht, Quellen-Dialog

Faden sieht jetzt aus wie im Design, hell und dunkel. Ein Notebook hat drei Spalten: Quellen, Chat und Studio. Ein Klick auf einen [[citation|Beleg]] öffnet die Quelle und springt zur markierten Stelle. PDFs zieht man einfach in das Fenster.

05
Entscheidungen und Alternativen

    

      
Gewählt
Beleg-Ansicht neben dem Chat
Auf großen Bildschirmen weichen Quellen und Studio, die Quelle bekommt Platz. Man kann weiterfragen, während sie offen ist. Auf dem Handy legt sie sich über den Tab.
Alternative
Eine eigene Seite wie im Design. Dann ginge der Zustand des Chats verloren, und eine gerade gestreamte Antwort hat noch keine ID für eine Adresse.

      
Gewählt
Text aus den Abschnitten zusammensetzen
[[assemble|assembleChunks]] findet die Überlappung und hängt nur den neuen Teil an. Jeder Abschnitt bekommt Start und Ende im Text. Das reicht für die Markierung.
Alternative
Start und Ende beim Einlesen speichern. Genauer, aber eine [[migration|Migration]], und alle vorhandenen Quellen müssten neu verarbeitet werden.

      
Gewählt
Eine Route zum Lesen
GET /api/sources/[id]/text. Laut Next.js-Doku sind [[serveraction|Server Actions]] für Änderungen gedacht und laufen nacheinander. Lesen ist ein normales GET.
Alternative
Eine Server Action, die den Text zurückgibt. Weniger Code, aber zwei schnelle Klicks warten aufeinander.

      
Gewählt
Farbschema im Cookie, Farben mit light-dark()
Der Server liest den [[cookie|Cookie]] und setzt die Klasse im ersten HTML. [[lightdark|light-dark()]] hält beide Werte jeder Farbe an einer Stelle.
Alternative
Das Paket next-themes oder localStorage. Dann weiß es erst das JavaScript im Browser, und die Seite blitzt kurz hell auf.

      
Gewählt
shadcn/ui mit Radix
Dialog, Menü und Schublade kümmern sich um Fokus, Escape-Taste und Screenreader. Der Code liegt bei uns und lässt sich frei anpassen.
Alternative
Alles selbst bauen. Ein guter Dialog ist schwer: Fokus festhalten, zurückgeben, Hintergrund sperren, [[aria|ARIA]]-Angaben.

      
Gewählt
Zustand eine Ebene höher, Chat nur versteckt
Der Workspace hält Auswahl, offenen Beleg und Uploads. Spalten werden per CSS ausgeblendet, nicht entfernt.
Alternative
Spalten je nach Tab ein- und aushängen. Einfacher zu lesen, aber [[usechat|useChat]] verlöre dabei eine laufende Antwort.

      
Gewählt
Mehrere PDFs nacheinander
Eine Datei nach der anderen, jede mit eigenem Status. Klappt alles, schließt der Dialog. Sonst bleibt er offen.
Alternative
Alle gleichzeitig. Schneller bei vielen Dateien, aber schwerer nachzuvollziehen, und der Server startet viele Verarbeitungen auf einmal.

      
Gewählt
Seitenleiste nur mit echten Funktionen
Übersicht, zuletzt aktive Notebooks, Neues Notebook, Farbschema, Abmelden. „Zuletzt aktiv“ kommt aus der letzten Frage.
Alternative
Alles aus dem Design übernehmen: Suche, Benachrichtigungen, Workspaces. Knöpfe ohne Funktion wirken im Live-Test unecht.

    

  


  
  

    
06
Was schiefgehen kann

    

      
Qualität
Eine Überlappung wird nicht erkannt
Dann hängt Faden die Abschnitte mit einer Leerzeile an. Kein Satz geht verloren, einer steht höchstens doppelt. Beim Völkerschlachtdenkmal wurden alle 14 Übergänge erkannt.

      
Qualität
Die PDF-Seite ist nur Text
Faden zeigt den gelesenen Text, kein Bild der Seite. Tabellen, Spalten und Bilder fehlen. Eine echte PDF-Ansicht mit PDF.js wäre ein nächster Schritt.

      
Betrieb
Upload während des Löschens
Notebooks mit „In Arbeit“-Quellen lassen sich nicht löschen. Eine Quelle auf „Wartet“ schon: Läuft ihr Upload gerade, kann danach noch eine Datei ohne Notebook in [[storage|Storage]] landen.

      
Betrieb
Lange Webseiten
Text und Webseiten haben keine Seiten. Die Beleg-Ansicht lädt den ganzen Text, bei Wikipedia „Leipzig“ etwa 230 KB. Das geht, ist aber nicht schlank.

      
Qualität
„Zuletzt aktiv“ ist eine Näherung
Faden liest die letzten 100 Fragen. Ist die letzte Frage eines Notebooks älter, zählt sein Erstelldatum.

      
Qualität
Farben, die im Dunkeln umschlagen
primary ist hell schwarz und dunkel hell. Der aktive Beleg war damit im Dunkelmodus unsichtbar. Gefunden im Screenshot, nicht im Test. Die Demo oben zeigt den Fehler.

      
Barrierefreiheit
Tabs auf dem Handy sind Umschalter
Die Tabs Quellen, Chat und Studio sind Knöpfe mit aria-pressed, kein vollständiges [[aria|ARIA]]-Tab-Muster mit Pfeiltasten. Einfacher, aber weniger komfortabel für Tastatur-Nutzer.

      
Sicherheit
Die neue Route gibt Quelltext heraus
Nur mit Login, und [[rls|RLS]] zeigt nur eigene Quellen. Fremde und gelöschte Quellen sehen gleich aus: [[http404|404]]. Der Text wird als Text gezeigt, nie als HTML.
